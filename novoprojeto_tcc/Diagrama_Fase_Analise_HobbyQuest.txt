 3. DIAGRAMA DE FLUXO DE DADOS (DFD) — NÍVEL 1 (Explosão do P4)
================================================================================

  Descrição: Detalhamento interno do processo P4 (Motor de Gamificação),
  que é o núcleo lógico mais complexo do sistema HobbyQuest.


  [Entrada: tarefa concluída + categoria + valor XP]
         │
         ▼
  ┌─────────────────────────┐
  │  P4.1: CALCULAR XP      │
  │                          │
  │  • Recebe hobby e qtd    │
  │  • Soma ao XP acumulado  │     ┌────────────────────────────┐
  │    da categoria           │────►│  D3: Dados de Progresso    │
  │  • Soma ao XP global     │     │  (atualiza XP da categoria │
  │  • Registra motivo/log   │     │   e XP total)              │
  └────────────┬──────────────┘     └────────────────────────────┘
               │
               │  [XP atualizado]
               ▼
  ┌─────────────────────────┐
  │  P4.2: AVALIAR LEVEL UP │
  │                          │
  │  • Verifica se XP >=     │
  │    (nível_atual × 100)   │
  │  • Se sim: incrementa    │
  │    nível da categoria    │
  │  • Dispara evento de     │──────► [Evento: LEVEL_UP]
  │    Level Up              │        → P5 (Fanfarra + Modal)
  └────────────┬──────────────┘
               │
               │  [estado atualizado]
               ▼
  ┌─────────────────────────┐
  │  P4.3: VERIFICAR        │
  │  CONQUISTAS (BADGES)     │
  │                          │
  │  • Itera array           │
  │    HQ.ACHIEVEMENTS[]     │
  │  • Executa função teste  │     ┌────────────────────────────┐
  │    booleana de cada badge│────►│  D4: Conquistas            │
  │  • Se true e não         │     │  (adiciona badge à lista   │
  │    desbloqueado: grava   │     │   de desbloqueados)        │
  │  • Dispara notificação   │     └────────────────────────────┘
  └────────────┬──────────────┘
               │                      ──────► [Evento: BADGE_UNLOCK]
               │  [verificação temporal]       → P5 (Som + Notificação)
               ▼
  ┌─────────────────────────┐
  │  P4.4: ATUALIZAR        │
  │  OFENSIVAS (STREAKS)     │
  │                          │
  │  • Compara data atual    │
  │    (YYYY-MM-DD) com      │     ┌────────────────────────────┐
  │    última data registrada│────►│  D4: Conquistas e Streaks  │
  │  • Se consecutivo:       │     │  (atualiza streak_atual,   │
  │    streak_atual++        │     │   melhor_streak, última    │
  │  • Se gap > 1 dia:       │     │   data de atividade)       │
  │    streak_atual = 1      │     └────────────────────────────┘
  │  • Atualiza melhor_streak│
  └─────────────────────────┘

 9. DIAGRAMA ENTIDADE-RELACIONAMENTO (ER) — MODELO LÓGICO
================================================================================

  Descrição: Representa o modelo lógico de dados persistidos no
  armazenamento local (localStorage) do HobbyQuest.


  ┌──────────────┐         ┌───────────────────┐         ┌──────────────────┐
  │              │  1   N  │                   │  1   3  │                  │
  │   USUÁRIO    │────────►│  SESSÃO ATIVA     │────────►│  PROGRESSO POR   │
  │              │         │  (sessionStorage) │         │  CATEGORIA       │
  │  PK: email   │         │                   │         │                  │
  │  senha       │         │  loggedIn: Bool    │         │  FK: email       │
  │  dataCadastro│         │  currentUser: Str  │         │  categoria: Enum │
  │              │         │                   │         │  xpAcumulado: Int│
  └──────┬───────┘         └───────────────────┘         │  nivelAtual: Int │
         │                                               │  tarefasFeitas   │
         │                                               └──────────────────┘
         │
         │  1   1
         ├──────────►┌──────────────────┐
         │           │  PERFIL          │
         │           │                  │
         │           │  FK: email       │
         │           │  codinome: Str   │
         │           │  avatar: Str     │
         │           └──────────────────┘
         │
         │  1   *
         ├──────────►┌──────────────────┐
         │           │  CONQUISTA       │
         │           │  (desbloqueada)  │
         │           │                  │
         │           │  FK: email       │
         │           │  badgeId: Str    │
         │           │  dataDesblq: Date│
         │           └──────────────────┘
         │
         │  1   1
         ├──────────►┌──────────────────┐
         │           │  STREAK          │
         │           │                  │
         │           │  FK: email       │
         │           │  streakAtual: Int│
         │           │  melhorStreak:Int│
         │           │  ultimaData: Date│
         │           └──────────────────┘
         │
         │  1   1
         └──────────►┌──────────────────┐
                     │  ACESSIBILIDADE  │
                     │                  │
                     │  FK: email       │
                     │  tema: Str       │
                     │  leitLimpa: Bool │
                     │  semDistrac: Bool│
                     └──────────────────┘


  CARDINALIDADES:
  ───────────────
  • USUÁRIO (1) ◄────────► (1) PERFIL
  • USUÁRIO (1) ◄────────► (3) PROGRESSO POR CATEGORIA  [Arte, Leitura, Fitness]
  • USUÁRIO (1) ◄────────► (*) CONQUISTA  [0 a N badges desbloqueados]
  • USUÁRIO (1) ◄────────► (1) STREAK
  • USUÁRIO (1) ◄────────► (1) ACESSIBILIDADE
